# 口语作业退回修改

- 教师在口语任务提交列表进入“听取、评价或退回”，填写原因并二次确认。
- 仅任务所属教师能退回已提交作业。任务已关闭或截止时，先开放并延长截止时间。
- 学生回到录音检查阶段，原题目、笔记、自评和所有录音保留；允许使用原录音重新提交，或使用每次退回额外增加的一次机会重录。
- 当前评价撤回，保存到退回历史；重交后重新评价。历史记录包含原因、时间、教师、原提交时间、录音 ID 和评价快照。
- 学生首页任务卡显示“已退回 · 待重交”，训练页与历史详情显示原因及继续入口。
- 新接口：POST `/api/v1/sessions/{session_id}/return`，请求 `{ "reason": "退回原因" }`。
- 数据库迁移：`9a6d2e4f810b`，为训练记录添加 JSON 退回历史，旧记录默认为空列表。
- 本地数据库已升级；服务器下次部署时需执行 Alembic 迁移（Docker 启动命令已自动执行）。
- 验证覆盖权限、重复退回、空原因、任务截止/关闭、原录音重交、额外重录上传、次数上限、再评价和多次退回。
