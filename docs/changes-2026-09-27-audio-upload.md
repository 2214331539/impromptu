# 跨浏览器录音上传修复

- 上传时不再只按浏览器声明的 MIME 类型判断，优先检测 WebM、碎片化 MP4/M4A、OGG、WAV/RF64、MP3、AAC 和 FLAC 容器。
- Safari 可能把 `ftyp` 放在 MP4 头部稍后位置，服务端会扫描合理的元数据范围；无法从文件头判断时，在有 FFmpeg 的环境使用 `ffprobe` 验证音频流。
- 支持 `video/webm`、`video/mp4`、`audio/m4a`、`audio/x-m4a`、`application/ogg` 等浏览器常见声明，并以检测到的真实容器选择临时文件扩展名。
- 录音校验、转码或 OSS 上传失败时会释放本次未保存的录音次数，避免学生因上传失败耗尽重录次数。
- 教师退回接口现在也能恢复“已完成演讲但没有任何录音”的失败上传记录；会保留题目、笔记和历史，不删除用户数据。
- 本地验证覆盖全部现有测试、错误上传不消耗次数、失败记录恢复和前端构建。
