# 2026-09-24 功能调整

## 题库

- 题目维护与抽题展示只显示题目内容，不再要求分类、难度、标签。旧字段在数据库/API 中保留兼容，避免破坏历史训练。
- 现有题库可按行批量追加，每批最多 200 道；保存后输入框保持打开，可继续添加下一批。
- 追加接口按去除首尾空白、忽略大小写的题目内容去重，跳过当前题库中已有的题目。
- AI 导入支持向选定题库追加，仍保留新建题库入口。

## 口语与写作任务管理

- 导航统一使用“口语任务”和“写作任务”。
- 教师可编辑、关闭及重新开放两类任务；关闭带确认弹窗。
- 更新接口：`PUT /api/v1/tasks/{id}`、`PUT /api/v1/writing/assignments/{id}`；沿用创建字段校验和教师归属校验。
- 口语已有会话后不能更换班级/题库，次数不得低于已经使用的次数，已经开始的阶段截止时间保留。
- 写作已有学生进入后不能换班级；已有正式提交后不能改检测策略和修改次数。标题、说明、日期等仍可编辑。
- 关闭/截止会阻止新的业务写入，保留已有草稿和提交，重新开放后可继续。

## 缓存与恢复

- 按账号、任务隔离本机缓存；教师创建/编辑表单、学生口语笔记及写作正文、任务列表筛选、页面滚动位置与编辑器光标位置可恢复。
- 首页/教师工作台显示上次未完成任务的恢复入口。
- 草稿每次输入先存本机，防抖串行同步服务器，防止旧请求覆盖新内容。网络恢复或重新进入后可继续同步。
- 写作页区分“本机已缓存”和“已同步”。刷新会恢复当前任务页面，重新登录后可通过恢复入口继续。
- 正式录音分段到达时将录音快照写入 IndexedDB；恢复未上传的录音后可回听、上传，成功上传后清理音频缓存。
- 录音硬件流不能跨刷新持续运行：能恢复的是浏览器已经产生并缓存的音频，不能承诺设备退出瞬间尚未生成的音频。离开不暂停服务端倒计时。
- 本机缓存只在同一浏览器/站点/账号内恢复；跨设备依赖已同步到服务器的内容。用户清除站点数据会清除本机缓存。

## 写作离开提醒

- React Router 使用 data router，站内链接、返回/前进等导航由 blocker 拦截，确认后保存并离开。
- 刷新/关闭使用浏览器原生 `beforeunload` 提示，具体提示文字及是否弹出由浏览器决定。
- 浏览器不允许网页禁止切换标签或退出应用；切换时尽力保存并记录离开，返回时弹窗提醒。
- 修改未再次提交期间隐藏上一版本语法提示；写作最终提交的重复请求按提交 ID 幂等返回。

## 首页加入班级

- 加入班级移至学生首页，展示已加入班级。
- 加入成功会刷新班级、首页、口语任务与写作任务相关查询。
- 首页分别展示口语与写作任务，两个模块共享同一班级成员关系。
